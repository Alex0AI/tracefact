# TraceFact-60 data card

## Summary

TraceFact-60 is a deterministic synthetic regression dataset for trace-based reliability rules. It contains 60 OATS 1.0 JSON traces: ten each for clean success, failed tests, repeated/looping tools, completion without evidence, cost spikes, and successful recovery.

## Creation and provenance

Every record is generated by `scripts/generate-dataset.ts`; no model, person, private repository, scraped conversation, or benchmark answer is included. Generation uses fixed timestamps and stable IDs. `dataset/index.json` records label, expected finding codes, provenance, and license per trace.

## Intended use

- deterministic unit/integration testing;
- demonstrating report and replay behavior without an API key;
- rule ablation and regression checks;
- examples for adapter authors.

## Out-of-scope use

Do not use this set to claim production accuracy, model quality, benchmark superiority, demographic fairness, or real-world generalization. The labels and samples were constructed from the same rule definitions being tested.

## Known limitations

The traces are small, English-only, structurally clean, and do not reproduce the full diversity, ambiguity, partial logging, concurrency, or privacy risk of production agent runs. Cost values are illustrative. Artifact hashes are fixture identifiers rather than content-derived production artifacts.
