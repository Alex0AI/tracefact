# Roadmap

## v0.1 — Evidence-first vertical slice

- [x] OATS 1.0 schema, TypeScript types, migration
- [x] Evidence Graph and nine deterministic failure rules
- [x] redacted hash-verified Replay Capsule
- [x] HTML, JSON, Markdown, SARIF
- [x] Codex, Gemini CLI, Browser Use, JSONL/OTel adapters
- [x] local drag-and-drop dashboard, CLI, Action, read-only MCP
- [x] 60 deterministic traces and reproducible rule experiment

## v0.2 — Compatibility hardening

- [ ] versioned real-world fixtures contributed by users with explicit redistribution consent
- [ ] OpenCode, agent-browser, and OpenHands adapters promoted only after compatibility matrices
- [ ] browser-side capsule creation and multi-run comparison UI
- [ ] false-positive review on at least 200 diverse public or consented runs

## v0.3 — Open evidence protocol

- [ ] signed capsule manifests and streaming capsules
- [ ] OpenInference semantic-convention alignment proposal
- [ ] adapter conformance kit and fuzz testing
- [ ] optional policy-as-code completion gates

Not scheduled: training or bundling a model, uploading private traces, or a benchmark-mixing global leaderboard.
